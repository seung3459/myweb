연차별 누적 LCC (현재가치, 천원)

역전 판정은 이 표의 금액을 정수 연차 단위로 직접 비교합니다. 차트 선분의 교차점(연차 사이)이 아닙니다.
각 연차의 최저 금액에 표시 · 전환 = 전년 대비 우열이 뒤바뀐 연차 · 갱신 = 교체비 발생 연차
차트의 빨간 세로선 = 마지막 전환 연차(그 해부터 분석기간 끝까지 우열이 유지됨)

실질할인율 산정 원본표

출처 : 한국은행 경제통계시스템(ECOS) — 시장금리(년) 국고채(10년) / 소비자물가지수 총지수(2020=100)
소비자물가상승률은 전년 지수 대비 산출 (2016년은 2015년 지수 94.861 기준)
실질할인율 d = ((1 + 국고채 10년평균) / (1 + 물가상승률 10년평균)) − 1
값을 수정하면 즉시 재계산됩니다. 빈 칸은 평균에서 제외됩니다.
